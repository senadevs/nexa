# Prompts de imagen — Nexa

Serie inicial generada con `image-gen` en modo nativo del host. Las referencias se usaron para
extraer lenguaje visual y paleta, no para copiar composiciones. El logo se compone en la interfaz;
las imágenes no contienen texto ni marcas.

## Dirección común

Escultura editorial premium; estudio cálido; papel mate, piedra mineral y metal negro texturizado;
luz direccional suave; sombras largas limpias; composición asimétrica con recorte seguro; paleta
exacta `#201F1C`, `#3F3B35`, `#D0C7BB`, `#FFFDF1`, `#FF5E1E`.

## Entrega

Las variantes se publican con slug `-v2` para conservar los originales. El script de optimización
genera `public/images/work/{marea,norte,orbita}-v2-{800,1400}.webp` y los recortes hero
`public/images/hero/{marea,orbita}-v2-{720,1280,portrait-820}.webp`.
